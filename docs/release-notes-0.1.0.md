## Сфера CRM 0.1.0

Первый публичный релиз: рабочий интерфейс CRM на примере данных.

### Что внутри

- Клиенты, сделки, воронка продаж с drag & drop, задачи, команда, журнал действий
- Дашборд с аналитикой на Recharts
- Пример данных: создание, редактирование, удаление и сброс
- Установщик для Windows (Inno Setup), без прав администратора

### Установка

Скачайте **SferaCRM-Setup-0.1.0.exe** ниже и запустите.
Требования: Windows 10/11 x64, Chrome или Edge.

### Важно

API и PostgreSQL пока не подключены: данные хранятся в браузере.
Следующий этап — аутентификация, мультитенантность и база.
